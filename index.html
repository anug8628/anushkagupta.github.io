select research projects:

3D Food Printing for Personalized Nutrition
Columbia University Creative Machines Lab • Spring 2023

developed custom food-3D printer software from scratch and engineered hardware modifications for multi-ingredient extrusion system. successfully executed 18-ingredient print using modified Slic3r software, custom G-code generation, and rheology-optimized food pastes. integrated CAD modeling, materials testing, and real-time extrusion control to create complex multi-course meals through additive manufacturing. featured by NSF | technical report

Cuff-Less Blood Pressure Monitoring with 3-Axis Accelerometer
University of California San Diego • Published IEEE EMBC 2019

developed novel cuff-less blood pressure monitoring technique using 3-axis accelerometer achieving correlation coefficients of r=0.97 for diastolic and r=0.96 for systolic pressure. designed signal processing pipeline and feature extraction algorithms incorporating ballistocardiogram analysis and multivariate regression. validated approach met AAMI criteria with errors of −0.02±3.82 mmHg (diastolic) and −0.59±7.46 mmHg (systolic) across LOOCV, demonstrating potential for embedded wearable clinical monitoring. IEEE publication

Deep Learning for Plant Root Segmentation
Salk Institute for Biological Studies

developed deep learning models for automated plant root segmentation from microscopy images. improved ground truth data collection pipeline and annotation quality to enhance model performance. applied computer vision techniques to accelerate biological research on plant root systems and growth patterns. research poster

gene expression mapping
Haskell • Parallel Computing

parallel implementation of inferring gene regulatory networks using an information theoretic approach with boolean networks. algorithm adopted from Barman & Kwon using mutual information-based feature selection (MIFS). built in Haskell with stack, featuring both sequential and parallel modes. generates boolean expressions for gene regulation and visualizes networks with graphviz. successfully tested on E. coli dataset with configurable k-input nodes per target. github

ryzz programming language
OCaml • Compiler Design

final project for programming languages & translators. developed custom imperative, strongly typed, strictly typed, statically scoped, and explicitly typed language from scratch. built complete compiler toolchain including lexer, parser, semantic analyzer, and code generator. implemented type checking, memory management, and runtime system. github

8th army - emergency operations system
Python • Geospatial Optimization

built in conjunction with US military to develop optimal system for designing emergency operations in unknown locations given geometric mapping data. case study on Japan extending to other regions. implements geometric discretization of regions, population density functions, vehicle routing algorithms, and assembly point optimization. uses PyVRP for routing, geopy for geocoding, and geopandas for spatial analysis. tackles real-world logistics for non-combatant evacuation operations. github
